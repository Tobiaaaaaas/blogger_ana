# crosscheck —— 量「矛盾复核」这一层值多少

**管什么**：量 02§10.5 那一步 —— 拿产出跟引文里查得出的字面对一遍，对不上的交模型重读，值多少。
**量的是 `idx`／`spec` 那两栏**（当时 §10.5 的全部）；2026-09-18 之后那一节另有「条件句」「同帖互斥」两栏，不在这一轮里。
**不管什么**：不是产品代码。不改 `blogger/` 一个字、不抓帖、不写判断缓存、不碰 `data/`、不动调度。

## 量的是什么

**跑在手上 `data/signals/` 的活产出上，不重跑全库。** 矛不矛盾是拿**已经落盘的行**跟引文对出来的；重判一遍得到的东西跟库里那份不是一回事，量不了「复核有没有改对」。

一轮下来 2629 行里查出 13 处（0.5%）—— `idx` 5 处、`spec` 8 处。方向那一栏不查（`hints.contradiction` 里写了为什么）。

| 臂 | 系统提示 | 喂帖文本 |
|:---|:---|:---|
| **A 带提示** | `CHECK_SYSTEM_PROMPT` | 帖 ＋「存疑的几处」 |
| **B 对照** | 同上 | 只有帖 |

两臂的系统提示**完全相同**，唯一的变量是那条提示。没有对照臂，分不清「改对了」是提示挣来的，还是模型自己重读一遍就会改。

```bash
set -a && source ./.deepseek_keys.env && set +a
python -m research.crosscheck scan
python -m research.crosscheck run --out research/crosscheck/run.json   # 26 次调用
python -m research.crosscheck cmp research/crosscheck/run.json
```

三份 json 都是证据，都留着：`run.json` 一轮、`run-lock.json` 二轮（加过「没被标出的行
逐字照抄」，**已撤**，见 §四）、`run-final.json` 三轮（撤掉之后复验）。

## 量出来的数

| 臂 | 改了 | 维持 |
|:---|---:|---:|
| A 带提示 | 9 | 4 |
| B 对照 | 9 | 4 |

**两臂改的是同一批 9 条**，只有 3 条结果不同。

### 一、提示值多少：3 条真错全在提示上

13 处逐条读过，真错 3 条：

| 帖 | 原产出 | A 带提示 | B 对照 |
|:---|:---|:---|:---|
| 中国技术玩家 06-12 | `+1 d:2026-08-03 上证50` | `上证指数` ✓ | `上证指数` ✓ |
| 云帆观市 01-07 | `-1 t5 上证指数`（引文写「今天」） | `today` ✓ | `today` ＋ 把错的 `t5` 留着 |
| 云帆观市 06-01 | `+1 t5 上证指数`（引文写「今天」） | `today` ✓ | 没动 ✗ |

**带提示 3 条全改对；对照臂改对 1 条、半对 1 条、没动 1 条。** 这三条正是「产出离开了引文里的字面」那一类 —— 也正是这一层唯一够得着的错。

第一条值得单独说：引文里写着「科创板」，正则该报 `科创50`，可**正则这个值本身也是错的** —— 原帖说的是「高价科技股为代表的科创板低头思故乡」，科创板是往下那一拨，`8月3日左右开启新的一段上涨` 说的是大盘。两臂都落 `上证指数`，都对。**这就是「查出来的值不作结论」那句话的实证。**

### 二、动的不止那一处：6 条改在标出的地方，3 条改在别处

A 臂那 9 条改动，落在哪儿：

| 落在哪 | 几条 | 例 |
|:---|---:|:---|
| 被标出来的那一处 | 6 | 云帆观市 06-01 的 `t5` → `today` |
| **只有别处** | 3 | 刘海娃娃 03-09：被标的那条 `week 创业板指` 一字未动，凭空多出一条 `t1 上证指数` |

还有一条两头都动：云帆观市 06-01 除改对那一处外，另丢了 `long 上证指数`、添了 `-1 t5 创业板指`。

**根子在「按帖替换」** —— 复核回来的是整帖产出，原样盖上去，没被标出的那几处也跟着换了。试过用提示词堵（§四），撤了。

### 三、一条读不出来的：对照臂也重写了 9/13

不带提示、只是重读一遍，9 条里 9 条都变了。**这个数读不出好坏** —— 库里的行是 `parse.runs=2` 两遍比对＋定夺出来的，这里的重读只有一遍，本来就不是一回事。要分清是「重读更好」还是「单遍抖动」，得再跑一条两遍的对照，这一轮没跑。

### 四、试过一版「锁死」，撤了

§二 那条连带看着像提示词没写清，于是又跑了一轮（`run-lock.json`，26 次调用）：在复核那一段里加一句「**除了标出来的那几处，别的一律照抄** —— 一行不许多、一行不许少、一个字不许改」。结果两头都不如一轮。

| | 一轮（不锁） | 二轮（锁死） |
|:---|---:|---:|
| A 臂改动条数 | 9 | 8 |
| 三处真错 | **3 条全改对** | 2 条 |
| 连带 | 4 处 | 3 处 |

**连带只治好了四分之一。** 四条连带里只有「我觉醒了 09-12 凭空添一条」不再发生，刘海娃娃 03-09、03-12 与云帆观市 06-01 三条照旧。

**代价是标出的那一处开始照抄正则的值。** 中国技术玩家 06-12 同一轮内分叉：

| 臂 | 产出 |
|:---|:---|
| A 带提示（锁死） | `+1 d:2026-08-03 科创50` ← 正则的值 |
| B 对照（同一份系统提示，只是不摆提示） | `+1 d:2026-08-03 上证指数` |

唯一变量是那条提示，而这一处按原帖是 A 错的：帖里注意事项第 1 条写着「高价高科技需要一段的回落」，`+1 科创50` 与它相抵。**「查出来的值不作结论」那条纪律，被「别处一律照抄」这句抵掉了** —— 模型在唯一允许动的地方照着查出来的字面改。06-23 同形（一轮判成不产，二轮落 `-1 d:2026-06-30 科创50`）。

两处都朝正则的字面倒，方向一致，所以撤掉了锁死那句，`CHECK_SYSTEM_PROMPT` 回到一轮那版（只多留一句「理由站得住就维持」，把文档里「以复核为准」那句话写进提示词）。

**撤完又跑了一轮验（`run-final.json`）** —— 四处关键行与一轮逐字相同：06-12 回 `上证指数`、06-23 回不产、云帆观市 01-07 与 06-01 与一轮一字不差，三处真错 3/3 改对。多留的那一句没带偏。

三轮 A 臂的改动条数分别是 **9 / 8 / 11** —— 同一份提示跑三遍差这么多，正说明 §三 那条读不出来的量有多大。

## 结论

1. **这一层抓得到它该抓的东西** —— 3 条真错全在查出的 13 处里，且带提示 3 条全改对。
2. **提示本身是有效的**，但只在 3/13 上改变了结果：其余 10 条，摆不摆提示模型给的一样。
3. **改动的范围比查出的宽** —— 查出的是「处」，交回模型的是「帖」，9 条改动里 3 条纯粹是连带。**拦不住，也不该拦**：试过写进提示词里禁掉，连带只少 1/4，反倒让标出的那一处开始照抄字面值。连带靠 `复核清单` 逐条打出来给人看。
4. 样本只有 13 处、每轮各跑一遍，上面的条数不宜当准数看 —— 同一份提示跑三遍，A 臂的改动条数是 9／8／11。朝哪个方向倒，三轮是一致的；倒了几条，不是个准数。
