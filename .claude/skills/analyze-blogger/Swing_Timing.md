**信号字段**（语义同 SKILL.md §2）：

| JSON 键 | 语义字段 | 取值 |
|:---|:---|:---|
| `pub` | `publish_time` | 帖子发布时间（posts JSON 中对应 `publish_date` 字段，格式 `YYYY-MM-DD HH:MM`，用于定位参考价 bar） |
| `d` | `direction` | `1` = bullish 看多；`-1` = bearish 看空 |
| `idx` | `target_index` | 数据 key 名（默认"上证指数"）；若帖子明确提到某指数/板块则按 SKILL.md §2 映射表标注对应指数 |
| `spec` | `time_horizon` | 预测周期编码，见 SKILL.md §3 表 |
| `summary` | 信号内容摘要 | ≤50 字的预测关键句概括 |
| `cat` | 参与状态 | 只有两个值：`scored` = 参与打分；`unscored` = 不计分 |

> **`cat` 的作用域**：它是**打分侧**字段（评分/榜单/报告用）。**回测的板块归属与选行不看 `cat`**——板块归属用 `board_of_spec(spec)`、波段候选用 `spec ≠ long`（二者在现有语料上等价，见 `poll.py` 2026-09-10 注）；只有 **live 卡**用 `cat == "scored"`。

**阈值参数**

| 参数 | 值 | 触发条件 |
|---|---|---|
| 多头开仓 `TO_LONG` | **2/3** | （空仓或刚刚平仓完）且ρ **>** TO_LONG 且 e>Q_open → 开多 |
| 空头开仓 `TO_SHORT` | **1 − TO_LONG = 1/3**（**运行时镜像 `1−TO_LONG`，非独立常量**） | （空仓或刚刚平仓完）且ρ **<** TO_SHORT 且 e>Q_open → 开空 |
| 多头平仓 `TX_LONG` | **1/2** | 持多且ρ **<** TX_LONG 且 e>Q_exit → 平多 |
| 空头平仓 `TX_SHORT` | **1 − TX_LONG = 1/2**（**运行时镜像 `1−TX_LONG`，非独立常量**） | 持空且ρ **>** TX_SHORT 且 e>Q_exit → 平空 |
| 开仓法定人数 `Q_open` | **10** | e **>** Q_open为开仓的必要不充分条件 |
| 平仓法定人数 `Q_exit` | **10** | e **>** Q_exit为平仓的必要不充分条件 |

> **配置单源**：`research/config.py` 只落 `HYST_TO_LONG = 2/3`、`HYST_TX_LONG = 1/2`（外加 `HYST_Q_OPEN`/`HYST_Q_EXIT`/`HYST_WINDOW`）；**空腿两个阈值不落配置，由 `research/combo/hyst.py` 在运行时从多头镜像派生**（`TO_SHORT = 1 − TO_LONG`、`TX_SHORT = 1 − TX_LONG`）——配置里**没有**独立的空头常量，改多头即改空头。ρ 与阈值的全部比较走**整数交叉相乘**（`b·分母 > 分子·e`），**不用 float**。另注：`config.THRESHOLD = 2/3` 是 **float**，只服务**超短逐档引擎**，与本文件的滞回阈值无关。


## 2. 状态机

```
当日判定，分以下三步：

第一步：输入：现持仓 pos∈{0,±1}，当日 e、多方观点 bull → ρ = bull/e。

第二步：如有持仓（pos≠0）：
平仓门：
  if 持多 且 ρ < TX_LONG 且 e > Q_exit → 平多（目标 0）
  if 持空 且 ρ > TX_SHORT 且 e > Q_exit → 平空（目标 0）
  其余情况不平仓

第三步：
如空仓（pos=0）或刚刚平仓完：
开仓门：
  if ρ > TO_LONG 且 e > Q_open → 开多（目标 1）
  if ρ < TO_SHORT 且 e > Q_open → 开空（目标 -1）
  其余情况不开仓
```

> 所有比较均为**严格不等**：ρ 恰等于阈值（如恰 2/3、恰 1/2）不触发开/平，维持原持仓。

> **同收盘换向**：第三步"刚刚平仓完"允许同日换向——先走平仓门（需 e>Q_exit），平出后再走开仓门（需 e>Q_open），两门都过且方向相反 → 同一 15:00 收盘完成 +1↔−1 换向（无隔日空仓）；只过平门 → 平至持币；`long` 模式开仓门不判开空，持多平出后只到 0 持币。

- `long` 模式 pos∈{0,1}：开仓门只判开多（ρ<TO_SHORT 不触发开空、保持持币）；平仓门与 both 相同（持多且 ρ<TX_LONG 且 e>Q_exit → 平多）。
