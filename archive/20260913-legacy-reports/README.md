旧栈（`opinion/` ＋ `research/` ＋ `briefing/` 那一套）产出的单博主报告，126 份，文件名一律带
`_direction` 后缀。

**为什么挪走**：新栈的产物口径是 `reports/<博主名>.md`，**不带后缀**（03§7）。两种命名混在一个
目录里，一眼看不出哪些是重建后真的产物 —— 挪走之后 `reports/` 里剩的三份就是全部真产物。

| 内容 | 说明 |

**这些报告里的数字与现在的口径对不上**，别拿来对照：判层在 09-09／09-10 改过（`nd` 档退役、
教义四微调），事后验证在 09-12 定案为「纯函数、不落盘」，报告的两档在 09-13 改为按**交易日跨度**分。
