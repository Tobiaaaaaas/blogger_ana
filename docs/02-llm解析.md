# 02 · llm解析

**管什么**：解析一条帖 —— 从这条帖里捕捉观点信号。
**不管什么**：哪些帖进来、结果怎么存 —— 都是调用方的事。

---

## 02§0 这一步做什么

**本文写的就是「判断规则」** —— 判定哪句话算一条观点信号、怎么给它定出方向／周期／对象的规则集（§1～§9）。它落成一份规则文本喂给模型（§11），也进判断缓存的指纹（03§2.2） —— 改规则就是改本文。

**规则之外另有一层字面辅助**（§10） —— 把这一帖里认得出的时间词、对象词、条件词、方向词列在帖文旁边（§10.1），把产出与引文、产出与产出各对一遍，对不上引文的、以及对得上但不该产的，都交回模型复核（§10.5）。两样都不下判：划表述的边界、落 `spec` 与 `idx`、抄引文，仍是模型自己下笔。

| 项 | 是什么 |
|:---|:---|
| **输入** | 一条帖 —— 连它的编号、发帖时间（含周几）、标题正文、行情注记（§2） |
| **输出** | 零到多条结构化数据 —— 产不出就是零条 |

本文只描述「解析一条帖」这一个动作。下列都不归本文：

| 不归本文 | 归哪 |
|:---|:---|
| 哪批帖送进来、一次送几条、按什么顺序 | 03（报告，全量）／06（推送，增量）；回测经 04 那一步读（05§8） |
| 怎么保证每条帖都被读过、一条都不漏 | 03／06 —— 本文不产出任何「我读过这条帖」的标记 |
| 要不要缓存、缓存在哪 | 03／06 |
| 结果存到哪、怎么存、什么时候作废 | 03／06 |
| 判出来的观点信号说对了没有、算不算分 | 03 |
| 怎么摆到卡片上 | 06 |

**两条链用的是同一套读法** —— 报告全量读、推送增量读（回测沿用报告那条），一条帖怎么读、读出来长什么样，一字不差。**旧栈（`old_push/briefing/`）是另一份实现** —— 读同一种帖、用同一套判据，机制与出参有出入，逐项见 §13。

### 0.1 一图流

```
一条帖（含发帖时间、周几、行情注记）
   │
   ▼
① 摆清单（代码）
   │   把这一帖里认得出的时间词／对象词／条件词／方向词列在帖文旁（§10.1）
   │
   ▼
② 逐帖判读（模型）
   │   一批一遍，跑 parse.runs 遍，各遍独立
   │   每一处产出自己带 d／spec／idx／quote
   │
   ▼
③ 强校验（代码）
   │   引文逐字回帖里搜 → 档位与对象进合法域（§10.2）
   │
   ▼
④ 比三元组（代码）＋ 分歧定夺（模型）
   │   各遍一致的不再花钱，对不上的那些帖才交模型逐遍审（§10.3）
   │
   ▼
⑤ 矛盾复核（代码找、模型判）
   │   对不上引文的、对得上但不该产的，连查出来的地方交模型重读（§10.5）
   │
   ▼
零到多条结构化数据
```

## 02§1 观点信号

**一条帖能读出几条观点信号，就看它包含几个三元组。**

### 1.1 核心预测句

一条帖由多个语句构成 —— 逐条提取前，先按博主的帖子结构特征定位核心预测句（一帖可能有 0 个或多个）；只有核心预测句才看三元组，其余语句（背景、铺垫、闲聊）不产出。

| 帖里同时有 | 挑哪一句 |
|:---|:---|
| 复盘 ＋ 未来预测 | 只捕捉未来预测那部分 |
| 形态句 ＋ 该周期的独立无条件方向句 | 以方向句成条 —— 帖内既有形态句「下周先抑后扬」，又有独立方向句「对于下周周线个人看涨」→ 产一条 `nweek`／看多，引文取方向句 |
| 立场含糊 ＋ 夹带明确预测句 | 捕捉那句 —— 「后市难料，但明天我看涨」→ 捕捉「明天看涨」 |
| 疑问句／引流式标题 ＋ 正文里的结论 | 只捕捉正文那句 —— 「明天A股会怎么走？」「下周要变天？」问了不等于答了 |

> **不许因为「先抑后扬」是形态就把这类真看多帖整条漏掉；也不许把它自行解读成看多。**

### 1.2 三元组

**观点信号** ＝ 博主给出的明确方向、说的是哪一段时间、落在哪只指数。三个分量在同一层 —— 序号只是下笔的先后，判读时互相参照、常常要同时看，不是筛完一道再进下一道：判 `d` 要拿 `idx` 的现值比点位，判 `idx` 要对着上证现值比合理范围，判 `spec` 要看整句在预测什么、又反过来框住 `d` 与 `idx`。

| 下笔先后 | 分量 | 问什么 | 必须有吗 |
|:---|:---|:---|:---|
| **①** | 方向 `d` | 是不是一个明确的、无条件的方向观点 | 必有 |
| **②** | 周期 `spec` | 说的是未来吗 —— 还是复盘、还是已经过期 | 可缺（缺了落第 5 个交易日） |
| **③** | 对象 `idx` | 预测的是哪个板块或指数，映射到哪一类（详见 §5.2） | 必有 |

## 02§2 输入

输入是一条帖的原文，加上系统备好的外部事实 —— 外部事实模型只读不写。

```
[3] 发帖 2026-09-01 10:00 周二｜缩量横盘别慌，九月行情可期！
<正文…>
[行情@发帖 2026-09-01 10:00] 盘中(30分钟线当根开盘)：上证指数≈… 创业板指≈… 沪深300≈… 上证50≈… 中证500≈… 中证1000≈… 科创50≈…
```

| 带上什么 | 用来判什么 |
|:---|:---|
| **编号** `[N]` | 模型指认是哪条帖 |
| **发帖时间 + 周几** | 判定「本周／今天」这类周期词的语义（§4.2）离不开发帖时间与周几，不能让模型从日期自己推 |
| **标题 + 正文** | 判断的唯一文本依据；引文从这里逐字取。标题与正文并列呈现、同等重要 —— 标题常直接给出预测结论；疑问句/引流话术式标题不代表预测，去正文找结论 |
| **行情注记** | ① 未点名指数时，对照上证现值判「合理范围」（§5.4）② 「目标点位高于现值 → 看多」（§3.1）③ 「低开／高开」这类相对说法 |

### 2.1 行情注记的口径

| 项 | 说明 |
|:---|:---|
| 喂哪几个指数 | 七个主指数 —— 上证指数／创业板指／沪深300／上证50／中证500／中证1000／科创50。双创不单列，它是创业板指与科创50 的组合 |
| 取哪一刻 | 发帖时刻 |
| 取哪个价 | 那一刻可获取的最新价格 |
| 盘中取哪根 | **盘中**（交易日 `9:30~11:30`、`13:00~15:00`）取 30 分钟线里**结束时刻严格晚于发帖时刻的第一根**的开盘价（10:20 发布 → `10:30` 那根；整点发布不回落：`10:00:00` 取 `10:30` 那根，不是刚收完的 `10:00` 那根） |
| 其余时候取哪根 | **其余**（`11:30`、`15:00` 本身，以及午休、盘后、盘前、休市）取 30 分钟线里**结束时刻不晚于发帖时刻的最后一根**的收盘价 —— 午休 → `11:30` 收盘；盘后 → 当日 `15:00` 收盘；盘前或休市 → 上一交易日末根 |
| 注记头 | 标明这一份是哪一种（`盘中(30分钟线当根开盘)` ／ `上一根(30分钟线收盘)`），模型据此知道这个数字的分量 |
| 30 分钟线结构 | 每指数每日 **8 根**（`10:00`／`10:30`／`11:00`／`11:30`／`13:30`／`14:00`／`14:30`／`15:00`），**bar 时间 = 收盘时间**；首根就是 9:30 那根（覆盖 9:30~10:00，标为 `10:00`），其开盘 ≈ 9:30 开盘价；末根收盘 = 当日收盘价 |
| 与 03 的参考价 | **同一个口径、同一个值** —— 注记就是 03 事后打分用的那个参考价；终点价也取这套 30 分钟线（03§3.3） |

### 2.2 注记必须在场

这一条管三条链 —— 报告与回测由调用方把行情备到这一步（01§10），推送的每一档自己备到本档时刻，备不到就不判本档（06§5.3）。

> **解析任何一条帖之前，行情必须已经覆盖到这条帖的发帖时刻。取不到 → 这条帖不解析。**

## 02§3 ① 方向 `d` —— 必有

### 3.1 什么算方向

只有两个取值：`1` 看多 ／ `-1` 看空。认不认，就看这处表述能不能落成「涨」或「跌」这一对反义。

| 帖里怎么说的 | 算不算 | 落成 |
|:---|:---|:---|
| 涨／看多／偏多／大方向向上 | 算 | `1` |
| 跌／看空／偏空 | 算 | `-1` |
| 震荡上涨 ／ 震荡下跌 | 算 —— 形态词里就带着涨跌 | `1` ／ `-1` |
| 弱势震荡 ／ 震荡调整 ／ 高位震荡回调 ／ 调整 | 算 —— 形态词带上了方向补语 | `-1` |
| 缩量调整 ／ 放量调整 | 不算 —— 修饰的是量能、不是方向，这一处读不出净方向（§6 模棱两可） | — |
| 收阳 ／ 收阴 | 算 —— 单一收法就是涨跌的同义表达 | `1` ／ `-1` |
| 预期点位高于参考价 ／ 低于参考价 | 算（参考价见 §2 的行情注记） | `1` ／ `-1` |
| 不看空／不看跌／不要悲观；不会深跌／不会跌破 | 算 —— 否定一个方向，给的就是它的反面 | `1` |
| 不看多／不看涨；不会大涨／不会创新高；没有好的行情 | 算 | `-1` |
| 有望涨／有望冲击 4200 点／还有反弹空间／反弹修复 | 算 —— 不必等一个「涨」字 | `1` |
| 需防备再次跳水／要小心杀跌 | 算 —— 告诫要防的那个方向就是方向 | `-1` |
| 高位反复筑顶／反复的诱多 | 算 —— 都是说往下 | `-1` |
| 震荡／筑底／洗盘／蓄势／拉锯／考验支撑 | 不算 —— 光一个形态词，不承诺往哪走 | — |
| 无净方向收法（「收小阳线或十字星」） | 不算 —— 两种收法摆在一起，等于没选 | — |
| 先抑后扬／先跌后涨／冲高回落／探底回升 | 不算 —— 整条并列摆着，没说终点在哪；落点明确偏在后段的算（「熬过了先抑的阶段，后扬才刚刚开始」） | `1` |
| 其余取值 | 一律丢掉 | — |

### 3.2 必须是无条件的

**方向不能挂在一个博主并未承诺会发生的前提上** —— 「破了3900就减仓」「守住4000不破才能…」「3900是多空分水岭」「放量就站稳，否则转震荡」一律不产。博主明显倾向某一分支 ≠ 方向。

| 项 | 怎么定 |
|:---|:---|
| **自测** | 这处表述能否不改意思地改写成「博主无条件预测 〔某指数〕在 〔某周期〕 〔涨／跌／到某点位〕」？不能 → 不产 |
| **条件挂在哪儿** | 挂在指数自己的走势上（「破了3900就减仓」「如果明天低开」）与挂在指数之外（外盘、政策、消息）都是前提，都走上面那条 |
| **判什么** | 判的是方向挂没挂在前提上，不是这一句里有没有条件词 —— 前提管不着的那一处，照产 |

### 3.3 操作动词就是方向

**博主做出或建议一个操作动作，等于表了态**，即使没有单独一句「大盘要涨/要跌」。条件式里内嵌的操作不算（「破了3900就减仓」，见 §3.2）；过去时的操作报告不算（「今天我把仓位加到了创业板」，那是仓位状态自述，见 §6）。

| 动作 | 方向 |
|:---|:---|
| 减仓／清仓／轻仓／止盈／逢高抛／卖出 | 看空 |
| 加仓／重仓／补仓／逢低买／抄底 | 看多 |

### 3.4 方向词必须出自原帖

产出一条结构化数据之前，逐字核对 —— 要把某个方向词安到这个三元组上，**那个词必须在原帖的 `title` 或 `content` 里搜得到**。

> **搜不到 = 编造。** 编造（凭空造出博主没说的话）与硬凑（把不是方向的读成方向）都不允许。
>
> 严禁替博主补一个他没说的方向词，严禁把本文的示例措辞搬进引文 —— 示例只示形状，不是可复制的原文。

## 02§4 ② 周期 `spec` —— 可缺

**「档」在本文＝周期档位**（`spec`），说的是一段时间；推送那个「档」是时刻表上的一个点（06§5.1） —— 同一个字，两回事。

### 4.1 全表

**周期必须通过语义理解读出，不是关键词匹配** —— 帖里出现「明天」二字，不代表这就是对明天的预测（「明天开始至本周五」说的是本周，「明天」只标起点）。博主说什么周期就落什么档：不扩展、不缩短、不随意假设，每档锁定一个精确验证终点。

| `spec` | 什么时候用 | 验证终点 |
|:---|:---|:---|
| `today` | 今天／今日／当天／下午／午后／尾盘 | 发帖当天收盘 |
| `t1` | 明天／明日／次日 | 发帖后第 1 个交易日 |
| `t2` | 后天 | 发帖后第 2 个交易日 |
| `tN` | N天后／N日内 且 N≤20 | 第 N 个交易日 |
| `t5` | 近期／短期／很快／马上／即将／不久／临近／未来几天／接下来／当前阶段／节前／节后／春节前／春节之前／假期前／假期之前／假期后／假期归来；没说周期 | 发帖后第 5 个交易日 |
| `monday`～`friday` | 周一～周五（指本周的那一天；「本周初」→ `monday`） | 发帖当周的那一天 |
| `week` | 本周／这周／本周内 | 发帖日所在那一周的最后交易日 |
| `nweek` | 下周／下周末 | 下一周的最后交易日 |
| `nmonday`～`nfriday` | 下周一～下周五（「下周初」→ `nmonday`） | 下周的那一天 |
| `month` | 月底前／月末前 | 当月最后交易日 |
| `nmonth` | 下个月／下月 | 下月最后交易日 |
| `d:YYYY-MM-DD` | 博主给了具体日期（「8 月 20 日会涨」） | 该日期 |
| `long` | 下半年、全年、今年、明年、中长期、未来／未来几个月、后市、后续、后期、三年、长线、最终、始终、N天后／N日内（N > 20） | 无 |

上表之外还有几条：

| 项 | 怎么定 |
|:---|:---|
| 区间的两头 | 「1-2天」「3-5天」这类 X-Y 天、「今天和明天」「最快下周一最迟下周二」这类明说两头的，一律取窗口最后那一天的那一档（→ `t2`／`t5`／`t1`／`ntuesday`），不两头各出一条 |
| 「明天」压过「周几」 | 同一处表述里「明天」与「周五」指的是同一天时，落 `t1`；明天正好是周五也一样 |
| 时间词出自哪一句 | 出自承诺方向的那一句 —— 引文里别处（铺垫、复盘）的时间词不作数；方向那半句自己没带时间词的落 `t5`（「今天开盘之后个股一度出现了普跌，我认为……并非是行情结束」里，「今天」只是回顾） |
| 交易日 | 一律指 A 股交易日，不是自然日 —— 「发帖后第 N 个交易日」从发帖日往后数（周五盘后说「明天」→ 验证周一） |
| 验证终点 | 就是博主说的那一天，**不顺延** —— 落在非交易日（周末、节假日）就没有可验证的终点，这条表述不成立、不产（§4.2）；整周、整月一个交易日都没有的，同理：那一格说的「最后交易日」根本不存在 |
| `d:` 档 | 帖里出现日期不等于预测 —— 只有**预测语境**才落 `d:YYYY-MM-DD`（「8月7日之前都是磨底」），回顾不产（「2月8日我还提醒了一次」）；日期与周期词同现时跟周期词走 —— 「本周到 8 月 20 日」落 `week`，不落 `d:` |

### 4.2 未来 / 复盘 / 过期

**「这处表述是不是对未来的承诺」是语义判断，归本文**；**「发帖时间是否已晚于验证终点收盘」与「终点落不到交易日」是按时间的机械判断，本文不做** —— 两者都要摊开交易日历才算得出，而交易日历不是本文的输入（§2 只有帖与行情注记）。

| 这处表述是 | 怎么办 |
|:---|:---|
| 对未来的承诺 | 捕捉 |
| 对已发生行情的回顾（复盘） | 不捕捉 |
| 说现在是什么样（状态描述：「已经进入调整期」「顶背离已经出现」） | 不捕捉 |

| 按时间判的（判据见 03§3.6 ②③、06§5.7） | 怎么判 |
|:---|:---|
| 终点落不到交易日 | 说的那天没开市 → 这条表述不成立（§4.1） |
| 发帖晚于终点收盘 | `pub` 不早于对应 `spec` 验证终点的收盘时间，**任何档位**一律如此；**边界取等** —— 正好是收盘那一刻（15:00:00）算「晚于」 |
| `today` 的合成 | 它的终点就是发帖当天 —— 上面两条对它合成一句：**发帖日必须是交易日，且发帖时刻在收盘前** |

### 4.3 没给周期时

| 情形 | 落哪 |
|:---|:---|
| 有方向、没给时间 | `t5`，正常计分（「减仓为主」「随时会涨」「肯定要涨但不知道什么时候」） |
| 有点位、没给时间 | `t5`，正常计分（「目标是 4260 点」「能到 4000」） |
| 有点位、给了时间 | 跟时间走（「今天下午能站上 4000」→ `today`；「明天站上 4100」→ `t1`；「下周到 4000」→ `nweek`） |

## 02§5 ③ 对象 `idx` —— 必有

### 5.1 只能是这八个

**上证指数 ／ 上证50 ／ 沪深300 ／ 中证500 ／ 中证1000 ／ 创业板指 ／ 科创50 ／ 双创** —— 只有这八个，其余一律落不到对象上。其中双创是组合（创业板指与科创50 各占一半）；深证成指、北证50、行业指数都不在其中，博主只谈这些的话捕捉不到观点信号。

### 5.2 映射表

| 帖里出现 | 预测对象 | 代码 |
|:---|:---|:---|
| 创业板／创业板指／创业板ETF | 创业板指 | 399006 |
| 科创／科创50／科创板／半导体／芯片 | 科创50 | 000688 |
| 小盘／成长／中证1000 | 中证1000 | 000852 |

| 沪深300 | 沪深300 | 000300 |
| 上证综指／上证／综指／大盘 | 上证指数 | 000001 |

### 5.3 对象跟着这一处表述走

预测对象是这一处表述里博主给出方向/时段/点位的那个对象，不跟着帖子主题、论据里提到的别的指数、或市场氛围漂移 —— 一条帖对上证和创业板各说一句，那是两个三元组，各成一条，不许揉成一条上证（去重与条数见 §7）。

### 5.4 未点名指数时的映射规则

**核心预测句未点名板块或指数时，`idx` 按下表定。** 参照是注记里上证指数的发帖时刻现值，不是模型记忆里的旧点位；「合理范围」＝ 上证现值 ± `parse.band`（§12，现值 0.10 —— 上证 3900 时即 3510～4290）。

| 情形 | 怎么办 |
|:---|:---|
| 给了预测点位，点位属于上证指数短期未来的合理范围 | `idx` = 上证指数 |
| 给了预测点位，点位不属于上证指数短期未来的合理范围（差出发帖时刻上证现值 ± `parse.band` 以上、明显是另一个指数的量级） | 不视为信号，不产 |
| 边界怎么算 | 比大小时取等，边界一律归严的那一侧 |
| 不靠点位反查 | 对不上上证就不猜 —— 不给它归到别的指数，这条预测作废 |
| 数不在 1000～20000 之间 | 不算点位 —— 年份、百分比、成交量都不是 |
| 一处引文给了几个点位 | 逐个比，有一个落在带里就放行 |
| 没给点位，给了方向预测 | `idx` = 上证指数（默认：对上证综指/大盘的判断） |

## 02§6 凑不成观点信号的情形

按缺哪个分量归类。这些说的是「这段话不算数」，不是「这帖作废」；一条帖里可以同时有几处各缺各的。

| 缺哪个 | 哪些情形 | 例子 |
|:---|:---|:---|
| ① 缺方向<br>（没有博主本人的明确方向） | **条件式** | 「破了3900就减仓」「守住3900看反弹」「放量突破才追」「冲高回落转守4000」「接下去每跌50点加0.5成」 |
|  | **状态假设**（与条件式同类） | 「在大家情绪再次上头的时候」「下周科技再高开或者再冲高的时候」「科创50指数大涨高潮之后」「短期跌多了反弹修复一下」 —— 把方向挂在「……的时候」「……之后」上，和挂在「若／如果」上是一回事 |
|  | **机制／目的推演** | 「主力资金砸盘要释放恐慌，恐慌量要出现，市场要加速探底」「情绪冰点的目的就是为接下来反弹做铺垫」 —— 讲的是「为什么会这样」「这件事为了什么」，是论述，不是对去向的承诺 |
|  | **观察句** | 「明天会怎样，先看4000反击」「下午A股市场主要看拉升」 —— 说的是看哪里，不是承诺往哪走；「看」后面跟点位、跟方向、跟板块都算 |
|  | **路径形态**（先A后B） | 「明天冲高回落」「下周先抑后扬」 |
|  | **周期词不救形态** | 「这周高开低走」「今天冲高回落」「下周探底回升」 —— 带周期词的形态句仍是形态句，没有一句独立无条件的方向句就不产 |
|  | **开盘形态** | 「周一我们的市场无疑会高开」「明天低开」 —— 说的是开盘那一刻，不是收盘（验证终点在收盘）；方向看同一句里有没有承诺走高，「继续创新高」照产 |
|  | **模棱两可** | 「可能涨也可能跌」「边走边看吧」「即将变盘」「不好说」「看市场情绪」；同一帖里方向摆了好几处、没有一处是明确净方向的 |
|  | **跨句指代** | 「我认为可能性很大」 —— 这一句自己没有方向词，方向要从邻句借才读得出来 |
|  | **骑墙** | 「不会大涨，但再创新低的可能性不大」「指数或许不会深跌，但会有很多人在个股上亏钱」「要么直接阳线突破，要么就是开始二次探底」 —— 同一处表述里摆开方向相反的两支，等于没选；不必是否定式并列，「要么A，要么B」同样是两支；后面再补一句主句也不算把它了结，「不会大跌，也不会大涨，而是缓慢爬升」仍是骑墙，不许读成「排除极端 ＋ 承诺温和上行」；同一个方向说了两遍不算骑墙 |
|  | **表态度不给动作** | 「多看少动」「观望吧」「控制好仓位」「以防御为主」「耐心等待」 —— 是态度、不是动作，不算 §3.3 的操作动词 |
|  | **立场自述** | 「看法不变」「维持观点」 —— 单说没变不算；同一帖里引出了具体论证的，按那个论证产 |
|  | **仓位状态自述** | 「还剩4成」「满仓持股」「我拿着不动」「我把仓位加到了创业板」 |
|  | **投资理念** | 「长期持有优质公司」 —— 理念自述，不是方向 |
|  | **转述他人** | 「机构认为底部在3700-3800」「券商觉得…」 —— 机构/券商的看法不是博主本人表态，博主以自己口吻明确背书才认 |
| ② 缺周期<br>（不是对未来的承诺） | **纯复盘** | 「昨天猜中了开头，却没猜中结尾」「今天这波下跌说明……」「这次探底回升很标准」 |
|  | **状态／背景句** | 「已经进入调整期」「顶背离已经出现」「目前处于上升趋势」「在趋势之上」「创新高」「很安全」「强势」「安心持股」「技术上存在反弹修复」「整体趋势是往下的」；「等 XX 筑底后上证走强」里上证只是受益方 —— 说现在是什么样，或主谓不是在预测上证未来涨跌 |
|  | **过期** | 见 §4.2（按时间的过期由 03§3.6 ③ 机械判） |
| ③ 缺对象<br>（落不到指数） | **只谈行业板块** | 全帖只谈有色、房地产、军工 |
|  | **未点名指数且点位不在上证合理范围** | 只说「市场」「行情」给了点位，但点位明显对不上上证短期合理范围 → 不产 |
| 三个都缺 | **无实质内容** | 只有话题标签（`#晒图笔记大赛#`）、平台活动、与股市无关的日常 |

## 02§7 一条帖能出几条观点信号

| 情形 | 几条 |
|:---|:---|
| 同一对象 + 同一周期 + 同一方向，在帖里重复说了几遍 | **一条** |
| 不同周期 | **各一条**（「今天市场会大涨」＋「这周市场启动的判断不变」= 两条） |
| 同一周期但不同对象 | **各一条** |
| 同一对象同一周期但方向相反 | **各一条** |
| 同一天的另一条帖说了同样的话 | **不去重** —— 本文只判一条帖，两条帖各算各的 |

**不做乘法** —— 别拿「一句话 × 几个周期 × 几个指数」去组合：「上证明天涨，创业板这周看好」是两条，不是四条。**不得只取近端周期、把远端丢掉，也不得把两个周期并成一条。** 各条的引文从载各自时间词的原句逐字截取（§9）。

## 02§8 输出字段

| 组 | 谁填 | 字段 |
|:---|:---|:---|
| **A 读帖判断** | 模型 | `d` · `spec` · `idx` · `quote` |
| **B 帖子身份** | 系统 | `post_id` · `pub` |

模型只写 A 组；`post_id`／`pub` 由系统按帖子补上，模型一律不写 —— 避免模型誊写编号、时间出错。所以一条结构化数据 = 6 个键；一条帖产不出就是一个空列表。**计分与否不在这里判** —— 那是报告统计环节从 `spec` 与 `pub` 算出来的（见 03）。

```json
{"post_id": "7514028836195041826", "pub": "2026-01-04 15:16",
 "d": 1, "spec": "t1", "idx": "上证指数",
 "quote": "明天大盘有望站上4100"}
```

## 02§9 `quote` 佐证原话

**这个三元组在帖子里的原话，用来佐证博主确实这么说过。**

| 规则 | 说明 |
|:---|:---|
| **必填** | 每条结构化数据都要有引文 |
| **限长** | **≤ `quote_limit` 字**（超了截到限长内，**不许为凑长度改写**；宁可短也不能改字） |
| **逐字** | 不许改写、润色、编造 |
| **可以是不连续的两段拼起来** | 段与段之间在原文里可以不挨着；每一段都要能逐字搜到 |
| **重复的几处并成一份** | 同一条重复出现（§10.2 去重）：各段按在帖里的先后接起来，段间用省略号；重复的、与别的段重叠的（同一处只留最长的那段）、接上就超 `quote_limit` 的，都不要 |
| **必须能佐证这个三元组** | 引文里得摆出三样：`idx` 的原话（点名的指数，或 §5.2 映射表里那个别名／板块词）、`d` 的原话、`spec` 的原话（时间词）。帖里没给的两样不要求 —— 没点名指数（§5.4 落默认的）与没说周期（§4.3 落 `t5` 的） |
| **与这条的方向无关的句子不算佐证** | 哪怕它在原文里、哪怕它载着时间词 |
| **截取起点** | 从载有时间承诺那句的句首附近截起，别只截丢掉时间词的后半句 |
| **来源** | `title` 或 `content`，两边都可以 |
| **引文宽窄不影响条数** | 引文是证据，不是容器 —— 两条可以引同一句原文 |

## 02§10 读帖流程

**五步的全程见 §0.1**，本节逐个说规矩。**代码只做查字面、比产出两样，判读、定夺与复核的结论都归模型**；按字面丢行的只有 §10.2 强校验那一道。

### 10.1 摆清单

**代码把这一帖里认得出的字面特征列在帖文旁边** —— 时间词（附 §4.1 查到的档位）、对象词（附 §5.2 查到的指数）、条件词、方向词，各照原话抄。

| 做什么 | 怎么定 |
|:---|:---|
| 粒度 | **整帖一份** —— 不切句、不编号；这些词在原帖的哪儿，模型自己找 |
| 重复 | 同一个词只列一次 |
| 认不出档位 | **不列** —— 词表是闭集，表外的词进不了清单 |
| 具体日期 | `d:` 那类**补上年份再列** —— 补出来早于发帖日的是明年那一个（§4.1） |
| 方向词 | **只列原话、不给方向** —— 词表出的是词义层面的值，句义层面的翻转（「不会大涨」）归模型，把值摆出来等于替它下判 |
| 同位置取最长 | 「不会大涨」压过「大涨」压过「涨」（时间词与对象词同理，§4.1／§5.2） |
| 条件词 | 只收**按 §3.2 判得死的那几句**里的词 —— 拿不准的一律不列 |
| 截断 | 超 `parse.per_post_limit` 字的正文保头 60%、尾 40%（§12） |
| 边界 | **只摆不判，也不是全集** —— 一个字都不删不加；代码认不出不等于帖里没有，§4.1 的档位表与 §5.2 的映射表仍要模型自己会查 |
| 可复现 | 切词与查表都是纯函数，同一份输入重跑逐字节相同 |

### 10.2 强校验

**在一条帖的产出上就地做**，各遍与定夺的产出都过 —— 不合格的直接丢：

| 检查 | 处置 |
|:---|:---|
| `d` 不是 `1`／`-1` | 丢掉 |
| `idx` 不在八个合法对象里 | 丢掉 |
| `spec` 不在档位表里，或语义荒谬（`t0`／`t99`／`d:2026-13-99`） | 丢掉 |
| `d:` 的具体日期早于发帖日 —— 是回顾，不是预测（§4.1） | 丢掉 |
| `quote` 缺失或为空 | 丢掉 |
| `quote` 超过 `quote_limit` 字（§9） | 截到限长内 —— 不丢行，截断后仍须逐字可搜 |
| `quote` 有任一段在这条帖的 `title`／`content` 里搜不到 | 丢掉 |
| 未点名上证的预测里，点位落在「上证现值 ± `parse.band`」外（§5.4） | 丢掉 —— 脚本按注记现值复算；引文里出现 §5.2 任一对象词即算点名，不查 |
| 同帖内同对象同周期同方向重复 | 只留一条 —— 引文并成一份（§9） |
| **代码只丢不改** | 丢了记名：哪条帖、哪句原话、**丢掉的是哪一处（方向／周期／对象）** |
| **拿不准的一律放行** | 宁可筛不完，不许冤枉 —— 跨 `title`／`content` 拼起来的引文照收；点位那一条取不到现值、引文里数不出点位，都不判 |

### 10.3 同一帖跑多次，分歧才交模型定夺

**同一条帖跑 N 遍**，每遍独立过 §10.2；N 取 §12 的 `parse.runs`（现值 2），N = 1 时无从可比，这一步退化成单纯的自查 —— 一份产出也照样交模型复核一遍。各遍的产出再按帖比三元组（`d`／`spec`／`idx`，**不看 `quote`**）；**一批里一处对不上的都没有 → 整批不调模型**。送模型的是**整条帖**，连同各遍在它上面的全部产出 —— 定夺要过的是这条帖的每一处产出，不只对不上的那几处；回喂时每一处产出都要带着「出自哪条帖」，模型只能靠这个认出引文属于谁，少了它会把 A 帖的引文安到 B 帖头上。

| 比出来 | 怎么办 |
|:---|:---|
| 各遍一样，或只差引文 | **不送模型** —— 直接取；同一条的引文**并成一份**（§10.2 去重那条） |
| 某一份多一条、或少一条 | 这一帖**送模型** |
| 条数相同，但三元组对不上 | 这一帖**送模型** |

**定夺拦这四样**：

| 拦什么 | 怎么认 |
|:---|:---|
| **形态被读成方向** | 引文里的方向词在原帖里搜不到 → 一律丢掉 |
| **周期编码错** | 「下周一」~「下周五」落错 `t1`／`nweek` → 改回 `nmonday`~`nfriday`，方向与引文一字不动 |
| **条件式硬凑方向** | 方向是从「守住/跌破/分水岭」或路径形态里压出来的，而帖内没有独立无条件的方向句 → 丢掉 |
| **骑墙** | 同一处表述里正反都说（§6）→ 丢掉；句尾补的那半句不算把它了结 |

**怎么定**：逐遍审每一处 —— 过不了上面四关的丢掉，剩下的并起来；不是从几遍里挑一份，也不是取交集。每遍还要分清是错了还是漏了，漏掉的那处要捞回来。

| 情形 | 怎么定 |
|:---|:---|
| 同一条在几份里都有 | 留下，引文并成一份（§9） |
| 只有一份提到、其余都没有 | 先当成别的遍**漏了** —— 过得了四关就留，过不了才丢 |
| 几遍的三元组对不上 | 逐个审它站不站得住：错的剔掉，对的都留 |

> **每一条都要与 N 份里的某一条逐字一致**（除被改过的 `spec`、以及 §9 并起来的引文） —— 不许新造引文，**不改 `d`**（方向词在原帖搜不到是丢，不是改），**不做乘法**，也不许把 N 份里没有的东西凭空补上。

### 10.4 失败粒度

**批是一轮调用，帖是结果。** 一批没调成只跳过这一批，其余批照常、已成的批照常交出去。

| 情形 | 处置 |
|:---|:---|
| 回来的不是那个带 `signals` 键的对象 | 这次调用没成 —— 重调一次（§11） |
| 回来的 `signals` 是空表 | **成** —— 这一批判过了，一条不产（§6） |
| 一批重调之后仍没成 | 这一批记名跳过，里面的帖下一轮重判 |
| 一次调用失败 | 不牵连其余的批；**绝不把「没判到」当成「判成不产」** |
| 各遍全都失败 | **不把空产出交给模型定夺** —— 那等于让它对着空气编 |
| 一遍调不通、其余遍成了 | **照常比、送定夺** —— 死掉的那一遍当它一条不产；这一批照样记名，下一轮重判 |
| 定夺没跑成 | 退回各遍产出的并集 —— 这一退没有「被丢掉」可言 |

### 10.5 矛盾复核

**产出是从引文里读出来的，再拿引文对一遍。** 引文逐字抄自帖文 —— 它写的是哪个指数、哪段时间，就是博主说的那个；产出跟它对不上，就是模型在引文之外自己补了一个值。**另两类是「对得上、但不该产」** —— 引文所在的那整句是条件句（§3.2）；同一帖里同对象同周期出现方向相反的两条（§6 骑墙）。

**查出的是几处，采纳的是整帖** —— 查出来的一律不直接改、也不直接丢，把这一帖连同查出来的地方交回模型，照全部判据重读一遍；没被标出的行也可能跟着换，一并记进清单，让人看得见。

| 查哪一栏 | 什么情况下报 |
|:---|:---|
| `idx` | 引文里查得出对象词（§5.2），而产出的 `idx` 不在查出的那几个里 |
| `spec` | 引文里查得出时间词（§4.1），而产出的 `spec` 解出的日期不在查出的那几个日期里 |
| 条件句 | **引文落在的那几句**（见下）**每一句**都是条件句（§3.2），而这一处产了方向 |
| 同帖互斥 | 同一帖里同 `idx`、同 `spec` 出现方向相反的两条 —— **两条都报**；只在产出内部比，不看帖文 |

**「引文落在的那几句」**＝引文逐段回帖文定位、各取落到的句子合起来；要每一句都是条件句才报，只要有一句没挂在条件上就放行（§3.2「前提管不着的那一处，照产」），某一段在帖里搜不到、或几段分处 `title` 与 `content`，一律不判。

| 不查的 | 因为 |
|:---|:---|
| 产出 `long` | 它是「20 个交易日以上」的开区间，引文里查得出某一天不等于与它冲突 |
| 引文里查不出值 | 那是**查不着**，不是对不上 —— 65% 的行引文里没有对象词，39% 没有时间词 |
| 「引文里同时有正反方向词」「整句只有形态词、没有方向词」「引文里一个方向词都没有」这三类 | 2026-09-18 逐条抽读：三类量的都是方向词表那 63 个词的封闭性 —— 承载方向的词常在表外（「逐步修复」「阳包阴」「不可能站上」「摸到 4000 点」），产出方向其实都有字面依据。与 `d` 那一栏一样：345 条里 0 条真错 |
| `d` 那一栏 | 方向词是词义层面的值，句义层面的翻转归模型（§3.1），字面反了不算数 |

**查出来的只是提示，不作结论** —— 这些都是字面查的，自己也会错。条件句那一栏更是如此：「这一句里有没有条件词」查得出，**「方向挂没挂在前提上」归模型**（§3.2）。**复核以模型为准**：答得出理由（引文只是论据、这一处针对的是另一个对象、方向并不挂在那句的条件上）就维持，答不出就改；重读之后一条都不产，也允许。原三元组 → 复核后的三元组记进清单，命令行逐条打出来。

**复核只跑一遍，不跑 `parse.runs` 遍** —— 它是带着这条提示重读一遍，不是重判；跑 `parse.runs` 遍就成了又一遍普通判读，提示也就没了作用。

## 02§11 模型网关

读一条帖这件事由谁来做、做不通怎么办。**规则文本就是本文 §1～§9 的判据**，落在 `blogger/parse/prompts.py`。参数值见 §12。

| 项 | 规矩 |
|:---|:---|
| **调哪个** | `parse.model`；网关地址 `parse.base_url` |
| **怎么调** | 温度固定 `0`、`max_tokens` 固定 `8192`、思考开关按调用点给 —— 三样写死在网关里，不是配置键 |
| **要什么回来** | 一律要求返回一个带 `signals` 键的 JSON 对象。不是合法 JSON、或合法却没有那个键 → 算这次调用没成，走重试（§10.4） |
| **调不通** | 连同首次一共试 `parse.max_retries` 次，间隔从 `parse.retry_delay` 秒起、逐次递增 |
| **硬超时** | 单次调用超过 `parse.call_deadline` 秒就断，按「没成」处理 |
| **全失败** | 抛错，不做「静默跳过」 —— 这一批判不出来就是这一轮没跑成，交给调用环节处置（03§6）。绝不把「没判出来」当成「这条帖没有观点」 |
| **进指纹的四样** | 规则文本、模型名、一条帖跑几遍、一次喂几条帖 —— 四者任一改，判断缓存整个作废、重判一遍（03§2.2）；规则文本含复核那一份（§10.5） |

## 02§13 旧栈口径

旧栈（`old_push/briefing/`）读同一种帖、用本文同一套判据 —— §1～§9 全部适用。规则文本落在 `old_push/opinion/prompts.py`，推送与报告共用同一份。差别只在下面这几处。

| 项 | 新栈 | 旧栈 |
|:---|:---|:---|
| **出参** | 整行 6 键，模型写 4 键（§8） | 整行 13 键，模型写 9 键 —— 比 §8 的 4 键多 `post_n`·`s`（强弱）·`cat`（计分与否）·`horizon`（卡面展示词）·`summary`；`post_id`·`pub`·`quote_ts`·`blogger` 由系统回填 |
| **`spec` 词表** | §4.1 全表 | 没有 `monday`～`friday` 与 `nmonday`～`nfriday` |
| **「下周一」** | 落 `nmonday`（§4.1） | 按发帖日分叉：那天是发帖后第 1 个交易日 → `t1`；否则 → `nweek_first` |
| **`tN` 上限** | N≤20 | N≤30 |
| **`d:` 的终点** | 不顺延 —— 落非交易日就不产（§4.1） | 顺延到下一交易日 |
| **「本周已走完」** | 不写进规则文本 —— 周六周日发的「本周」，终点早于发帖，由「发帖晚于终点收盘」判掉（§4.2） | 规则文本里判：周六周日发帖说「本周」 —— 复盘 → 不产；预判下周 → 编 `nweek` |
| **读法** | 一批一遍，跑 `parse.runs` 遍，三元组对不上的才交模型定夺；定夺拦四样（§10.3）＋ 矛盾复核（§10.5） | 逐帖标注一遍 ＋ 一条复核通道，拦同样那四样（`DOCTRINE_REVIEW` 10 条），没有多遍比对 |
| **无方向帖的去向** | 零条 | 逐帖到案 —— 每条帖要么出行、要么进 `no_view` 并写明理由（`opinion/schema.py` 的 `NO_VIEW_REASONS`） |
| **阈值从哪来** | `config.json` 的 `parse` 一节（§12） | 不读 `config.json` —— 值写在规则文本与常量里，与 §5.4／§9 同值 |

**这九处之外两栈同一条** —— §1 的核心预测句、§3 的方向判据（含否定式／委婉式／戒备式／筑顶式、操作动词、方向词必须出自原帖）、§5 的对象映射与「带外不产」、§6 的凑不成情形、§7 的条数、§9 的引文纪律。
