# 07 · 术语对照表

> **用途**：① 全系统统一用词 —— 同一个概念只准有一个名字；② 并存期回读旧文档时查旧称 —— 旧一代规格在 `legacy/`，另有 `.claude/skills/analyze-blogger/SKILL.md` 与 `Swing_Timing.md`。
> **状态**：已补齐。新增概念时同步加一行，别处不得再造同义词。

## 怎么用

- 写文档、对话里提到某个东西时，**只用「大白话」这一列的名字**
- 旧文档里看不懂的词，来「旧称」列查 —— 旧称**只在翻译时出现**，正文一律不用
- 一个名字登记后**不再改**；要换名，得同时改掉所有引用
- **字段名**（如周期档位那个字段叫 `spec`）可以直接写 —— 它是数据格式的一部分，不是代码
- **命令与路径**（如 `python -m research.corpus`、`data/posts/`）照写 —— 那是操作步骤与数据位置

## B 判断规则

| 大白话 | 一句话定义 | 旧称 |
|:---|:---|:---|
| 判断规则 | 判定「哪句话算一条观点信号」以及「怎么给它定周期」的规则集 | **教义**、判层规则、doctrine |
| 无条件 | 帖子里的话不带「如果…就…」这类前提，是直接表态 | — |
| 条件式 | 观点挂在一个博主并未承诺会发生的前提上（「破了 3900 就减仓」） | — |
| 路径形态 | 只描述「先怎样、后怎样」，没承诺往哪走（「冲高回落」「先抑后扬」） | — |
| 净方向 | 一句独立的、无条件的、明确说涨还是跌的话 | — |
| 操作动词 | 减仓／清仓／加仓／抄底这类动作，本身等于表了态 | 操作句 |
| 仓位状态自述 | 只报持仓成数、不动方向（「还剩 4 成」）——不算表态 | 状态句 |
| 复盘 | 回顾已经发生的行情 —— 不算表态 | 回顾 |
| 转述他人 | 说的是别人的看法，不是博主自己的 | — |
| 模棱两可 | 方向不明，或干脆声明不赌（「边走边看吧」） | — |
| 板块映射 | 帖子里提到的行业或板块该算到哪只指数头上 | — |
| 别名归一 | 「上证综指」「上证」「综指」统一认作「上证指数」 | — |
| 弃行 | 一行观点信号没过校验，整行丢掉 | **修剪**、丢弃该行 |
| 机械拦截 | 发帖时间晚于该周期的验证终点收盘时间 → **03 判成「无效-过时」并从库里删掉**（与博主说了什么无关，纯按时间判）。**语义上的「过期」归 02，时间的兜底归 03** | — |
| 作废重算 | 判断规则改了，已缓存的判断结果与新规则不符，必须整批重来 | 缓存失效 |

## F 运维与数据

| 大白话 | 一句话定义 | 旧称 |
|:---|:---|:---|
| 内容校验码 | 给一段规则文本算出的短码；文本一变，码就变，用来判断缓存是否作废 | **指纹** |
| 写入缓存 | 把判断结果存下来，下次不重判 | **固化** |
| 自动重新抽取 | 发现数据缺了，自动补跑一次抽取 | **自愈** |
| 补写正文 | 正文缺失时从备份或重新抓取补上 —— **已废止**：标题与正文在抓取命令内部一次拿齐，不再有这道分步工序 | **回填**、补正文 |
| 替换 | 新数据顶掉旧数据 | **顶替** |
| 不做提示 | 出错但不声张，继续往下走 | **静默** |
| 该帖不产生观点 | 这条帖读过了，没有任何可提取的表态 | **路过** |
| 定位原文 | 从一条观点信号回溯到它出自哪条帖、哪句话 | **溯源** |
| 抓帖 | 从今日头条把博主发的帖子抓下来存进 `data/posts/` | 爬取 |
| 抓帖记录 | 上次抓到哪一条了，下次从这儿继续 | 增量位点 |
| **起始时间** | 这次抓取往回翻到哪（参数名 **`begin_date`**）。**由调用环节算好传入**，抓取自己不判断。它**既是翻页的停点，也是硬边界** —— 早于它的帖不入库。抓取与校验**传同一个值** | 爬取起点 |
| 补齐 | 手动动作：读总览里落后的博主，各自从 `scrape_time` 算出起点，逐个调抓取。**「该从哪续」只在这里判** | 补全 |

| 重叠余量 | 续抓的新起点不取「抓取截止」本身，而取它**所在那一日的零点** —— 防边界漏帖；退多退少都不花钱（靠去重） | — |
| 视频帖 | 博主发的视频内容 —— **不入库**：判定即丢，不写主文件、不计帖数（见 01§8） | — |
| **置顶帖** | 博主挂在主页顶上的那条 —— **不入库**，与视频帖同样处置。**可能有好几条**，日期任意：它是公告位、插在列表最前面，会搅乱倒序翻页并让帖子的时间跨度失真（见 01§3.4） | — |
| **已完成记录** | 一份「**判过但不入库**」的帖子编号清单 —— 视频帖与置顶帖共用。记它是为了**永不重抓**：否则每轮都要为它们再取一次详情页（见 01§1） | — |
| 本人身份 | 这条条目确实是本博主发的 —— 从 feed 带的用户信息认。**认不出的一律不收** | — |
| 热度游标 | feed 里的 `behot_time`，约等于抓取时刻；**绝不当发帖时间用**（发帖时间只认接口的 `publish_time`，退而取 `create_time`）。**三个都是头条接口的字段名**，我们落库存成 `pub`（见 01§7） | — |
| 列表页噪声 | 列表里形如「`博主名`：发布了一篇内容-今日头条」的占位条，不是博主的帖子，丢掉 | — |
| 列表接口 / 详情页 | 取文字的两个地方：**列表**给标题（`title`）、**详情页**给全文（`content`）。在抓取命令内部一次走完 | — |
| 抓取区间 | 一份帖子数据的 `[起始时间, 抓取截止]` | — |
| 对齐 | 把所有博主的「抓取截止」放在一起比，看谁的数据不齐 | — |
| **交易日历** | 哪天开市。**官方日历**（`data/market/trade_cal.json`）—— 交易所事先公布，所以**含未来**（01§10.3）。数日子只认它 | — |
| **行情覆盖到哪天** | 上证日线的末根。算价只认它（01§10.3）。**与交易日历是两件事** —— 行情缺一天不会让那天变成非交易日 | — |

## G 一词两义（重点）

这些词在不同地方意思不同，读到时要看清上下文。

| 词 | 义一 | 义二 |
|:---|:---|:---|
| **回落** | **博主术语**：冲高回落 —— 是判断对象，出现在帖子原话里 | **程序行为**：取不到值时退回默认值（新规格已改称「续显」，不再用「回落」） |
| **汇总** | 报告里把多条观点信号合成一张表 | 推送里把多条观点信号写成一段话 |
| **波段** | 从发帖日到验证终点隔了 2 个交易日及以上 —— **推送（06§2）、报告（03§3.4）、对比（04§3.4）共用这一条** | — |
| **超短** | 从发帖日到验证终点隔 0 或 1 个交易日 —— 同上共用一条 | — |
| **上证** | 帖子里博主说的「上证」，通常指上证指数 | ~~交易日历的基准~~ —— 已废止：日历改用官方日历，不再由上证行情派生（01§10.3） |
| **权重** | 得分公式里没有权重这回事 | 双创 = 创业板指与科创50 各占一半 |
| **档** | 周期档位：一条观点信号说的是哪一段时间（`today`／`t1`／`week`…） | 推送档：一天里有哪几个推送时刻 |
| **窗口** | 回看窗口：这次推送往回看多久以内的帖子 | 抽取批次：一次喂给模型的那批帖 |

## H 不是自造词，照用

下面这些是通用金融或通用技术用语，**不算自造术语**，正文里可以直接用：

> 净值 · 回撤 · 年化 · 超额收益 · 波动率 · 盯市（mark-to-market） · 换手率 · 卡玛比

（其中 **卡玛比**（年化收益 ÷ 最大回撤）与 **换手率**（改仓次数 ÷ 回测年数）已收进 05§7。）

**VaR · 滑点 · 手续费不在上列 —— 本栈用不上。** VaR 不做（05§7）；滑点与手续费整个不计：回测的净值、逐笔收益、各项指标全是毛数，没有成本这一项（05§5.1）。
