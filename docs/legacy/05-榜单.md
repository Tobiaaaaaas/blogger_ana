# 05 · 榜单

**这份文档管什么**：把所有博主放在一起排名 —— 谁有资格参与、按什么排、取前几名、没上榜的怎么标。
**这份文档不管什么**：个体报告怎么出（见 03）；得分怎么算（见 01§10）。

**注意**：榜单和个体报告是**两套资格、两套口径** —— 有资格上个体报告 ≠ 有资格进榜。

---

## 05§0 边界：系统里有两套榜单 〔主干〕

系统产出**两套互相独立的榜单**，它们的**读者、宇宙、口径都不一样**：

| | ① **全博主横向对比** | ② **波段专项榜** |
|:---|:---|:---|
| 回答什么 | 所有博主里，谁的方向判断质量最好 | 那套「看多比例超 2/3 就持多」的共识信号，跟参与投票的成员比，排第几 |
| 参赛者 | **全部博主**（经资格筛选） | **固定的那批波段成员**（30 位）+ **一行「综合」** |
| 产物 | `reports/comparison_direction.md` | `research/quality/reports/composite_swing_compare.md` |
| 本文 | §1–§5 详写 | §6 一段话交代 |

**两套榜的数字不能互相引用。** 同一位博主在两边都有名次，但**参赛者不同、样本不同**，「第 5 名」在两边不是一回事。

## 05§1 全博主横向对比：一图流 〔主干〕

```
全部博主（信号目录下的每一个文件）
   │
   ├─ 先过滤：这个人的帖子跨度够 6 个月吗？2026 年以来信号超过 10 条吗？
   │     否 → 不参与打分，只在报告开头单列一句「为什么不参与」
   │
   ▼ 通过的进入榜单宇宙
   │
   ├─ 再过滤：只保留**上证指数**的计分信号
   │     （他对创业板、科创50 的判断，不计入榜单排名）
   │
   ▼ 每人一组得分
   │
   ├──→ 总榜          ：计分信号 ≥30 条 且 平均分 >0  → 按**夏普**降序 → 前 20
   ├──→ 两档分榜 ×2   ：该档 ≥10 条 且 平均分 >0.1  → 按**平均分**降序 → 前 20
   ├──→ 方向榜 ×2     ：该向 ≥10 条 且 平均分 >0.1  → 按**平均分**降序 → 前 20
   │
   ▼
   没上榜的 → 在榜下补一句，说明是「不够格」还是「条数太少」
   ▼
   最后：逐人列出**覆盖与集中度警告**
```

## 05§2 资格：谁才有资格参与打分 〔主干〕

进入榜单宇宙要同时满足两条：

| 条件 | 门槛 | 为什么 |
|:---|:---|:---|
| 帖子跨度 | **≥ 6 个月** | 只发了两周帖的人，样本不足以谈「判断质量」 |
| 2026 年以来信号数 | **> 10 条** | 同上，信号太少的平均分没有意义 |

**不满足的人不参与打分与排名**，但在报告开头**逐位列出**，并写明他卡在哪一条（跨度几个月、信号几条）。

> **这一条很重要**：榜单只排「够格的人」。看到某人没出现，先确认他是不是压根没进宇宙 —— 而不是「排得靠后没显示」。

**排名只认上证指数的信号。** 即使某位博主对创业板、科创50 的判断很准，那些信号也**不进榜单排名**。

> 理由：不同指数的波动幅度差很多（创业板弹性远大于上证），混在一起比，等于奖励「专挑波动大的指数说」的人。统一到上证，比较才是同一把尺子。

信号身上还要有**得分**才进统计 —— 「不计分 / 待验证 / 无效-过时 / 报错」这几类状态不进（见 01§10）。

## 05§3 三种榜 〔主干〕

### 3.1 总榜

总榜的门槛与排序：

- **资格**：计分信号 **≥ 30 条** 且 平均分 **> 0**
- **排序键**：**夏普**（= 平均分 ÷ 波动率）**降序**
- **取前 20 名**

波动率为 0 或信号不足 2 条 → 夏普算不出来，**排到榜尾**（不是排到榜首）。

### 3.2 两档分榜

把信号按「多久能验证」分成两档，**各排一张榜**：

| 档 | 判据 |
|:---|:---|
| **超短期** | 从发帖日到验证终点隔 **0 或 1 个交易日** |
| **波段** | 隔 **2 个交易日及以上** |

- **资格**：**该档 ≥ 10 条** 且 平均分 **> 0.1**
- **排序键**：**平均分** 降序
- **取前 20 名**

这一档的判据是**交易日跨度**，与推送/回测判断「超短还是波段」用的**卡片周期词**是**两套判据**，两者会分叉 —— 见 01§12。

### 3.3 方向榜

把信号按方向切开，**各排一张榜**：

| 榜 | 收录 |
|:---|:---|
| **看多榜** | 只看方向 = 看多的信号 |
| **看空榜** | 只看方向 = 看空的信号 |

- **资格**：**该方向 ≥ 10 条** 且 平均分 **> 0.1**
- **排序键**：**平均分** 降序
- **取前 20 名**
- **表里不再列「看多/看空」两列** —— 这一榜里方向是固定的，列了也是冗余

> **这两张榜必须分开看。** A 股博主普遍偏多头（看多信号远多于看空），合在一起排，名次基本由「谁看多得多」决定，看空能力完全体现不出来。看空榜往往是**检验一个人是不是只会喊多**的地方。

### 3.4 三种榜的资格与排序键一览

| 榜 | 样本 | 资格：条数 | 资格：平均分 | 排序键 |
|:---|:---|:---|:---|:---|
| 总榜 | 全部计分信号 | ≥ 30 | **> 0** | **夏普** |
| 两档分榜 | 该档的计分信号 | ≥ 10 | > 0.1 | 平均分 |
| 方向榜 | 该方向的计分信号 | ≥ 10 | > 0.1 | 平均分 |

总榜资格里的「平均分 > 0」是**盈亏分界**（不赚钱的人不进总榜）；分榜里的「> 0.1」比 0 略高一点，是为了**挡掉「平均分约等于 0」的噪声**。

## 05§4 没上榜的人怎么标 〔主干〕

每张榜下面补一句，把落榜者按**条数**分成三档：

| 情况 | 怎么标 |
|:---|:---|
| 该组 **≥ 5 条** 但不够资格 | **逐位列名** + 条数 + 「未达 10 条 / 平均分 ≤ 0.1 未上榜」 |
| 该组 **1–4 条** | 只写「**另 N 位该组信号 < 5 条**」—— **不列名** |
| 该组 **0 条** | **没有任何提示**（⚠️ 见待定 #19） |

总榜落榜者的标注口径略不同：写「**不参与总榜排名**（计分信号 < 30 或 平均分 ≤ 0，统计无意义）」+ 逐位的条数与平均分。

> **⚠️ 见待定 #19**：「该组 0 条信号」的人既不上榜、也不出现在任何提示里 —— **无声消失**。读者无法区分「他这档 0 条」和「他根本没进榜单宇宙」。这是本文档认为**应当修**的一处。

如果某张榜**一个人都不够格**，表里写一行「无符合资格博主（该组信号 < 10 条 或 平均分 ≤ 0.1）」，不留空表。

资格人数超过 20 时，榜下注明「本榜共 N 位符合资格，仅取前 20 名上榜」。**不足 20 就不写这句** —— 那句「仅取前 20」会让人误以为后面还藏着人。

## 05§5 覆盖与集中度警告 〔主干〕

榜单末尾逐人列出**信号在时间上分布得正不正常**。四类警告：

| 警告 | 触发条件 | 说的是什么 |
|:---|:---|:---|
| 覆盖不足 | 有信号的月份 **< 3 个** | 样本太短 |
| 高度集中 | 单个信号的月份占全部信号 **≥ 50%** | 平均分基本由这一个月决定 |
| 轻度集中 | 单月占比 **≥ 33%** | 同上，程度轻些 |
| 月份缺口 | 相邻两个有信号的月份之间**隔了 ≥ 2 个月**（≥ 3 个月加严重标记） | 中间一段时间他完全不发声 |

一个人**一条可打分信号都没有**时，这里写「0 条可打分信号」，**不跳过**。

> **这一节是榜单的「免责声明」。** 榜上第 3 名可能是一个信号全挤在两个月里的人 —— 他的名次对那两个月之外的时间**没有任何预测力**。看榜必须配合这一节。

## 05§6 波段专项榜（简述）〔细节〕

另一套榜，参赛者是**固定的那批波段成员**（30 位）+ **一行「综合」**。「综合」= 那套共识信号本身，即「该板块看多比例 > 2/3 就记一条看多」，验证用固定的第 5 个交易日收盘。

| 项 | 值 |
|:---|:---|
| 资格 | N **≥ 10** 且 平均分 **> 0.1** |
| 排序键 | **平均分** 降序 |
| 取前几名 | **不截断** —— 达标的全部列名，未达标的列在榜尾并逐一注明卡在哪一条 |
| 成员侧口径 | 各人**按自己的周期档位和目标指数**打分，再取波段档（跨度 ≥ 2 交易日） |
| 综合侧口径 | **固定 t5 · 上证指数** |

**这张榜的口径是不对称的**：成员按各自周期/标的算，综合固定 t5/上证。同表排序比的是「方向性质量」，**不是同一标的同一期限**。看空腿样本很少，结论要用「平均分 / 正确率」措辞，不要说「看空能力更强」。

与 §1 那套榜的关系：成员宇宙相同（都是波段成员），但**样本不同** —— 专项榜的成员侧取的是**波段档**，§1 的两档分榜取的是**全部上证计分信号再切档**。同一个人的 N 在两张榜上可以不一样。

## 05§7 常见误解 〔主干〕

**「总榜第 1 = 最会看盘的人」**
不是。总榜排的是**这套打分口径下的名次**：只看上证、只算计分信号、按夏普排。他没被排到的那些判断（创业板、科创50、不计分的长期观点）**完全没进统计**。

**「榜上没看到某人 = 他排得靠后」**
不一定。他可能**根本没进榜单宇宙**（跨度不足 6 个月 / 2026 年信号 ≤ 10 条），报告开头单列了。也可能他这档 0 条信号 —— 那种情况目前**什么提示都没有**（见待定 #19）。

**「夏普高 = 赚得多」**
不是。夏普 = 平均分 ÷ 波动率，是**每单位不稳定换来的平均分**。一个平均分 +1.5、波动 0.5 的人（夏普 3.0）会排在平均分 +2.5、波动 2.0 的人（夏普 1.25）前面。

**「两档分榜的『波段』和推送卡片上的『波段』是一回事」**
**不是。** 分榜按**交易日跨度**（≥2 天）；推送按**卡片上的周期词**。两套判据会分叉，见 01§12。

**「看多榜和看空榜合起来看就是总榜」**
不是。两张榜各自有资格门槛，某人可能上得了看多榜、上不了看空榜（看空信号不足 10 条）。而且总榜是按夏普排的，跟两张分榜的名次没有换算关系。

**「名次变了说明他水平变了」**
不一定。名次同时受**他自己**（新信号）和**别人**（别人的新信号）影响，还受**门槛**影响 —— 一个人从第 8 掉到第 12，可能只是第 11 名那个人这周多了 3 条好信号。

**「报告里的正确率 = 回测里那个 80%」**
**不是。** 正确率是**单条信号**得分 > 0 的比例；回测里的那个是**往返盈利比例**，即**一次完整买卖**毛收益 > 0 的比例。见 04§7.3。

**「榜单的数字可以直接拿到实盘用」**
不可以。这是**信号质量的横截面排名**，不含交易成本、不含仓位管理、不含择时。看谁的方向判断质量高是可以的；把它当成收益预期不行。

## 05§8 怎么跑 〔细节〕

```bash
# ① 全博主横向对比（总榜 / 两档分榜 / 方向榜）
python scripts/eval/comparison_all.py
#    → reports/comparison_direction.md

# ② 波段专项榜
python -m research.quality.run_compare
#    → research/quality/reports/composite_swing_compare.md
#       research/quality/reports/composite_swing_compare.csv
#       research/quality/reports/composite_swing_signals.csv
```

两者都**依赖已经算好的信号文件**，不重新调模型。信号文件不在，重跑也不会变出新结果。

## 05§9 已知的过时设计 〔细节〕

| 遗留物 | 情况 |
|:---|:---|
| `research/quality/reports/composite_swing_compare.md` 之外的另一份榜单产物 | 是**更早的快照**，与「同源重算」的专项榜**大面积对不上**（同一个人的条数和平均分都不一样）。两者确实调同一个算分函数，但**产物不同步**，且**没有任何地方标注它已过时** —— 谁拿到哪份看到哪份 |
| `research/README.md` 里对专项榜成员数的描述 | 有一处把某类成员的人数写小了（实际更多），依赖它的池子划分会跟着错 |
| 总榜资格里的「平均分 > 0」 | 与「> 0.1」的门槛不一致，是历史遗留的差异。**是否该统一，见待定 #21** |
