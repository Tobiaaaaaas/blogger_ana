# 判例

**管什么**：02 的规则是怎么定下来的 —— 哪些帖踩过、人是怎么裁的、哪几条已能靠条文自决。
**不管什么**：不是规格。规则本身在 [02-llm解析.md](../02-llm解析.md)，本文只留立法理由与实例。

---

## 四份怎么读

| 文件 | 是什么 |
|:---|:---|
| `第一轮.md` | 同一份帖文、同一份行情、同一份提示词判两遍，结果不同的那些帖 —— 逐条摊开等人给裁定 |
| `第二轮.md` | 同上，用的是判例经验并进 02 之后的那版提示词 |
| `经验-第一轮.md` | `第一轮.md` 里已裁定的那些抽出来的规则，逐条记下出自哪些帖；**已并进 02** |
| `经验-第二轮.md` | 同上，第二批；**待并进 02** |

**裁定后才有经验。** `第一轮.md`／`第二轮.md` 是原料，`经验-*.md` 是提炼物 —— 规则并进 02 之后，这里留来路。

**剔除不重排编号。** 只靠 02 现有条文就能定下哪一遍对的争议，从原料里剔除并记进经验那份；编号一律不重排 —— 甲-55 之后仍是甲-55。

## 怎么产出

`第一轮.md`／`第二轮.md` 由 `jitter draft` 出草稿、人填裁定而成 —— 那把尺子已随 02 换代退役，见 `archive/20260916-旧解析流程/README.md`。**这两份不接受覆盖** —— 一旦填了裁定，重跑一次冲掉就等于白填。
