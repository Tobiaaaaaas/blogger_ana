## 02§6 凑不成观点信号的情形

「若／如果」从句整个忽略 —— 从句不产，主句自己有没有方向，看主句（甲-39 上证那一句就产了，周期按 02§4.1 的周一～周五落 `thursday`）。

| 缺哪个      | 哪些情形                 | 例子                                                                                                                                                                                                  | 判例                       |
| :---------- | ------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------- |
| ① 缺方向    | 状态假设（与条件式同类） | 「在大家情绪再次上头的时候」「下周科技再高开或者再冲高的时候」「科创50指数大涨高潮之后」「短期跌多了反弹修复一下」—— 把方向挂在「……的时候」「……之后」上，和挂在「若／如果」上是一回事                 | 甲-27／甲-38／甲-39／甲-40 |
|             | 骑墙                     | 「不会大涨，但再创新低的可能性不大」「指数或许不会深跌，但会有很多人在个股上亏钱」—— 同一处表述里正反都说，等于没选；后面再补一句主句也不算把它了结（「不会大跌，也不会大涨，而是缓慢爬升」仍是骑墙） | 甲-19／甲-28／试跑         |
|             | 表态度不给动作           | 「多看少动」「观望吧」「控制好仓位」—— 是态度、不是动作，不算 §3.3 的操作动词                                                                                                                         | 甲-23                      |
|             | 立场自述                 | 「看法不变」「维持观点」—— 单说没变不算；同一帖里引出了具体论证的，按那个论证产                                                                                                                       | 甲-8                       |
