
# 注意

报告和推送都有llm解析帖子的过程，前者收集并全量解析，后者实时收集并增量解析。两种提取规则完全一致。

- 抓取
- llm解析
- 单博主报告
- 全博主对比
- 回测
- 推送

1. 抓取是帖子抓取功能，在单博主报告、推送中需要用到
2. llm解析是对抓取的帖子进行大模型解析并输出结构化观点数据，单博主报告、推送中用到
3. 单博主报告是对某一博主的全量帖子进行提取分析统计，输出的机构化观点数据需要保存。包括两个功能：新博主入库和旧博主更新
4. 全博主对比是对全部库中的博主表现进行统计分析，首步骤是对所有博主进行单博主报告更新
5. 回测是使用所有博主的经过lllm解析后的结构化数据通过策略进行回测，首步骤是对所有博主进行单博主报告更新
6. 推送是抓取指定博主池的增量帖子并实时解析推送支飞书上



- 帖子：博主发布的所有带文字的帖子，包括有明确观点的和其他（复盘的，模棱两可的），不包括视频
- 观点：对指数未来的预测，判断，有明确的方向性

# 报告流程

做什么：分析一位博主的预测观点的准确度


## 爬虫抓原始贴
输入：博主的某一个帖子的链接

抓取博主在某一时间区间（【起始时间，抓取那一刻】）里的所有带文字的帖子，视频用文字占位，我们不做视频的解析。




# 博主报告（新博主入库/旧博主更新）

1. 抓贴 + 行情数据补充
2. llm解析 + 输出结构化数据
3. 统计打分
4. 输出报告



## 抓贴

- 直接全量抓取（固定开始时间到现在）

## 行情补充

- 各指数30分钟行情数据
