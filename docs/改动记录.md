什么时候改过、还欠着什么，翻这一份。

- **改动记录**：日期 ＋ 改了什么。**新的在上面**
- **待补**：还没定的事。定了的当场划掉（`~~…~~`）并写明结论，行留着不删 ——
  看得到这条路是怎么走过来的

两份都是**流水**，不是规格：写正文时不必读它们，改正文时记得回来加一行。

## 通用 · 格式规范

六份正文共用的写法。**只讲格式，不改逻辑** —— 逻辑的改动进各节自己的「改动记录」。

| 项 | 规矩 |
|:---|:---|
| **粗体** | 只留三种：行首标签、硬约束（绝不／必须／一律／不许／永不）、整格即标签的表格单元格。句中强调一律不加粗 |
| **表格** | 一列里要么整列加粗（它是标签列），要么整列不加粗。同一列里有的粗有的不粗 = 没写完 |
| **节标题** | 名词短语，不带副题。副题的内容搬到该节首句 |
| **破折号** | 一律 ` —— `（前后各一个空格） |
| **用词** | 「本档」不写「这一档」；阈值叫「阈值」，榜的条数／均分线叫「资格线」 |
| **一图流** | 每一步带序号 ①②③…，六份一致 |
| **跨文档** | 同一件事只在最正主的那一份详写，别处一行指过去（`本文不写第二套`／`与 X§Y 同一口径`） |
| **围栏块** | 原样保留，不受上面任何一条管 —— 里面是命令行、图示与真实产出 |
